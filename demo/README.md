# AI 老师 · 竞品讲题流程复刻 Demo

这是一个面向小学 4—6 年级的单题讲解原型。当前范围严格聚焦：孩子已经有一道错题，通过相机拍入后，AI 老师怎样像竞品一样自动讲解，并一步步让孩子做对。

## 当前复刻流程

1. 相机拍题并框选单题；也可以从相册上传真实图片。
2. 确认后直接进入 AI 老师，不出现“和老师一起读题”或额外开始按钮。
3. 题目、题型和“解题关键”跟随语音逐步流式出现。
4. 老师在关键处弹出四选一理解检查。
5. 选错只播放新的提示，题目保持打开，提示结束后必须重新选择。
6. 选对后自动继续第一步讲解，并在“你明白了吗？”处停下来等待孩子点击继续。
7. 继续后展示第二步、答案和方法小结。

底部相机、按住说话、打字追问和暂停按钮在讲解过程中持续可用。语音或文字追问会立即中断当前讲解，只回答新问题；回答结束后由孩子决定何时继续。

## 拍题和识别

- 页面使用真实文件输入，可在手机浏览器请求相机，也可选择相册图片。
- `server.py` 的 `/api/ocr` 使用 macOS Vision 做本地文字识别。
- 当前内置油、苹果、图书三类演示题数据；OCR 命中后切换对应讲解内容，其他题目会生成通用讲解骨架。
- 顶部“修改识别结果”可人工修正 OCR 文本。

## 语音

- 主演示题使用 12 段 `zh-CN-XiaoxiaoNeural` 神经语音和 242 个逐词时间点，字幕与内容状态同步。
- 所有数学表达进入语音前都会规范化：`1/4` 读作“四分之一”，`36 ÷ 3/4` 读作“三十六除以四分之三”，不会读成“斜杠”。
- 上传的动态题目在没有预生成音频时回退到浏览器中文语音，但仍执行同一套数学读法规范化。正式产品应接入可实时生成、支持逐词时间戳的商业 TTS 服务。

## 本地运行

在本目录执行：

```bash
python3 server.py 4173
```

然后访问 <http://127.0.0.1:4173/>。

若需要重新编译 OCR 辅助程序：

```bash
swiftc scripts/ocr_problem.swift -framework Vision -framework AppKit -o scripts/ocr_problem
```

## 推荐体验路径

1. 在拍题页点击绿色确认按钮，观察内容与语音自动流式出现。
2. 理解检查先故意选 `1/4`，确认错误提示结束后仍可重新选择。
3. 再选 `3/4`，等待第一步讲解结束，点击“继续”完成整题。
4. 讲解过程中随时点击“按住说话”或键盘按钮，确认当前语音立即停止且不会重读旧内容。
5. 返回拍题页，从相册上传其他题目，验证 OCR 后自动开讲。

竞品相机画面和教师头像均来自用户提供的视频取证帧；交互图标使用 Phosphor Icons。
